Gemma on-device weights (bundled `.litertlm` only)
===================================================

The learner app **does not** download model weights over the network. All
Gemma inference uses **`assets/models/gemma-4-E2B-it.litertlm`** shipped in the
app bundle and installed with **`FlutterGemma.installModel`…`fromAsset`**.

Setup
-----

1. Place **`gemma-4-E2B-it.litertlm`** next to this file.
2. List it under **`flutter: assets:`** in **`pubspec.yaml`** (see repo).
3. Build and run. First launch may show a **progress panel on the home hub**
   while the plugin copies the asset into its storage.

Routing
-------

- After onboarding, users land on **`/home`**; the hub calls **`ensureReady()`**
  before daily topics.
- If the file is **not** in **`AssetManifest.json`** (e.g. slim build mistake),
  **`ensureReady()`** fails with a clear error — fix **`pubspec.yaml`** and rebuild.
  There is no HTTP fallback.

Optional tuning (free-space hints; optional tooling)
-------------------------------------------------

Compile-time defines (defaults in **`lib/llm/model_prepare_config.dart`**):

  IKAMVA_MODEL_ESTIMATED_MB=2048
  IKAMVA_MODEL_HEADROOM_MB=256
  IKAMVA_MODEL_MIN_FREE_MB=2048

CI / desktop
------------

**`flutter test`** on desktop does not load the mobile plugin; generation throws
**`LlmUnavailableException`** on non-Android/iOS targets.

**iOS Simulator:** LiteRT may fail on GPU; the app retries **CPU** (try **Low RAM**
in Settings or a physical device).

Privacy: inference stays on-device.

See **`docs/model_delivery.md`** and **`learner_app/README.md`**.
